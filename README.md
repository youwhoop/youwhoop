# youwhoop

自建服务、组网与自动化脚本的折腾记录。仓库以**私有存档**为主，公开的多是模板与说明。

## 在折腾什么

- **站点** — Next.js 影视聚合站的部署与 Docker 化，TMDB 元数据接入
- **组网** — EasyTier P2P 组网、Cloudflare Tunnel 内网穿透与多隧道编排
- **反代** — Lucky 反向代理、ACME 自动签发、DDNS 与自定义登录页
- **脚本** — PowerShell / Python 的批量运维、成员管理与巡检小工具

## 说明

配置类仓库默认私有：其中含证书、密钥与内网地址，不做公开。公开内容只放通用写法与工具，不含任何凭证。
